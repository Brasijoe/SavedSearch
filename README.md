# Saved Search Watcher

A Windows desktop app that watches your Kleinanzeigen saved searches and shows new ads.

## Download

**[Download the latest installer](https://github.com/Brasijoe/SavedSearch/releases/latest)** (Windows, `.exe`)

1. Run the downloaded `Saved Search Watcher Setup ….exe`.
2. Windows may show a SmartScreen warning because the app isn't signed. Click **More info**, then **Run anyway**.

Your searches and settings stay on your own PC. Sync between PCs is optional and uses your own GitHub account: in Settings, set the sync repository to one of your own (for example `yourname/saved-searches`).
